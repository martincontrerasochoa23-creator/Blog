FASES DEL CICLO DE VIDA DE SOFTWARE

¿Qué es el Ciclo de Vida del Software?

Es la "receta" o el paso a paso que siguen los programadores desde que se les ocurre una idea hasta que la aplicación o el videojuego está listo en el celular o la computadora de los usuarios.

VENTAJAS DEL CICLO DE VIDA DE SOFTWARE


-Proporciona un esquema claro y estandarizado con fases bien definidas para todo el equipo de desarrollo. -Facilita la detección temprana de errores o fallos en el diseño, lo que reduce los gastos totales del proyecto. -Fomenta la coordinación y la colaboración constante entre los desarrolladores, los administradores y los clientes.

DESVENTAJAS DEL CICLO DE VIDA DE SOFTWARE


-En modelos tradicionales (como el de cascada), modificar los requisitos una vez avanzado el proyecto es muy costoso y difícil. -La planeación y documentación rigurosa pueden alargar los tiempos iniciales antes de ver un resultado funcional. -El usuario o cliente suele esperar hasta el final del proceso para ver el sistema en funcionamiento.

Competencias de egreso


Al terminar la carrera de Ingeniería en Software, los egresados podrán crear programas, aplicaciones y sistemas que ayuden a resolver problemas de la vida cotidiana. Sabrán analizar necesidades, diseñar aplicaciones, programarlas, comprobar que funcionen correctamente y mejorarlas cuando sea necesario. También podrán trabajar en equipo y organizar proyectos tecnológicos para crear soluciones útiles para las personas.

Áreas de desempeño profesional


Especificación de requisitos: Identificar qué necesitan los usuarios y qué debe hacer el programa para resolver sus problemas.


Análisis: Estudiar el problema y la información necesaria para encontrar la mejor manera de desarrollar el software.


Diseño: Planear cómo se verá y funcionará el programa antes de comenzar a crearlo.


Construcción: Programar y desarrollar el software, escribiendo el código que permite que funcione.


Pruebas: Comprobar que el programa funcione correctamente, detectar errores y corregirlos.


Administración de proyectos: Organizar las tareas, el tiempo y el trabajo del equipo para lograr que el software se desarrolle de manera ordenada.

CONCLUSIONES FINALES DEL EQUIPO

El ciclo de vida del software se relaciona directamente con el plan de estudios de Ingenieria en Software, porque las materias que se cursan durante las carreras ayudan a desarrollar las habilidades necesarias para cada etapa de la creación de un programa o proyecto profesional.


Por ejemplo, la programación permite construir aplicaciones, el diseño ayuda a planear cómo funcionarán y las pruebas permiten encontrar y corregir errores.También se aprende sobre mantenimiento y administración de proyetos. En conclusión, el plan de estudios prepara a los estudiantes para desarrollar software de manera organizada, desde la idea inicial hasta su mejora y actualización.
